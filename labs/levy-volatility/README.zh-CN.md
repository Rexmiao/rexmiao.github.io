# Lévy 波动率实验室

[English](README.md) · **简体中文**

本项目用美元兑日元日度汇率构造波动率代理，再拟合 Lévy 驱动的 Ornstein–Uhlenbeck（OU）方差模型。网页可以查看训练和检验区间、比较样本外预测，并观察正跳跃及其随时间衰减的过程。

## 本地运行

使用 Python 3.10 或更新版本，在本目录执行：

```powershell
python scripts/model.py
python -m http.server 8080 --bind 127.0.0.1
```

打开 `http://127.0.0.1:8080/`。第一个命令从随项目提供的 `data/observations.csv` 重建 `data/results.json`。线上和本地网页读取同一份结果文件。

## 数据与模型

[数据来源与清洗说明](data-methodology/)列出汇率和美股的采集方式、清洗规则，以及如何构造评估目标。

汇率来自美联储 H.10 的纽约中午参考报价，单位为每美元对应的日元数。用六次有效报价计算最近五次对数变化，再将平方均值乘以 252，得到年化方差代理。数据范围、字段及来源见[数据说明](data/DATA.md)。

模型用正的指数分布跳跃描述波动冲击，并让方差在冲击之间以 λ 的速率衰减。跳跃按齐次泊松过程到达。平稳分布为 Gamma，形状参数 k、尺度 θ、均值 m = kθ，跳跃率为 λk。前 80% 的观测用于估计平稳矩和一期持续性。测试阶段固定已估参数，每次预测只读取预测起点已知的观测。

在预测期限 h，条件期望方差为 m + (Vₜ − m) exp(−λh)。网页将它与衰减系数 0.94 的 EWMA 和持平预测比较。三种模型预测同一个目标，即未来指定观测日结束时的五期方差代理。QLIKE 按方差计算，RMSE 按年化波动率计算，数值越小代表样本外误差越低。

一期预测的起点与目标有四期收益率重叠。五期和 22 期预测的起点和目标不重叠，连续的检验目标之间仍有重叠。模型直接把方差代理当作状态。当一笔较大的旧收益率退出窗口时，观测方差可能降到模型预测区间以下。相同均值和持续性的 AR(1) 会给出同样的点预测。可通过区间覆盖率检验跳跃分布。

## 美股波动率预测对照

同一网页展示 SPY、NVDA、JPM、AMD、QQQ、AVGO、MU、SNDK 和 NBIS 的样本外汇总结果。可比较固定训练期均值、EWMA、HAR 和 Gamma–OU 对未来 1、5、22 个交易日平均年化方差的预测。日线对照还包括 GARCH。

日线口径使用复权收盘到收盘的对数收益平方。分钟线口径把一分钟行情汇总为五分钟采样，计算常规交易时段已实现方差，再加上复权隔夜对数收益平方。七个长期标的有 527 个共同日线预测起点和 190 个共同分钟线预测起点。NBIS 的日线单独评估，有 85 个预测起点。NBIS 的分钟线与 SNDK 的两个口径均显示样本不足。分钟线评估要求七个长期标的的历史与目标窗口完整对齐，因此不同口径的样本日期可能不同。

QLIKE 报告同一批预测起点上相对固定训练期均值模型的损失差，负值表示损失较低。RMSE 的单位是年化波动率百分点。请在选定的方差口径、标的和预测期限下比较模型。

[美股结果总结](index.html#equity-findings)按口径和期限统计各标的的领先模型，并列出 Gamma–OU 同时优于 HAR 和 EWMA 的情形。排名按完整精度的分数计算。两两对照领先的标的仍可能由其他模型取得最低误差。NBIS 的短期日线评估有独立的预测起点。结果反映这些历史样本的点预测表现。

浏览器读取[汇总结果](data/equity-results.json)。若要从原始评估结果重新导出汇总文件，可向脚本传入本地美股研究的结果目录：

```powershell
python scripts/export_equity_results.py "<path-to-equity-study>/results"
```

原始评估文件和行情数据存于本地项目 `D:\Dropbox\量化反思总结\Levy波动率建模\equity-study`。

## 美股逐标的清洗审计

[交互审计](data-methodology/#cleaning-audit)逐标的展示原始数量、有效观测、剔除日期和原因。日线以交易日统计行情覆盖与有效收益。分钟线分别统计原始 K 线、常规时段 K 线、5 分钟区间和有效方差交易日。清洗记录和用于模型评估的连续窗口分别统计。

月历时间轴沿用审计的标的和频率选择。点击日期可查看可用的数据阶段、缺失或剔除原因。月历基于导出的交易日历。分钟线的审计文件记录一组常见的交易日计数，并对各项计数不同的交易日保存实际值。

准备好本地美股研究数据及其依赖后，可以在当前目录重新生成[审计数据](data/equity-cleaning.json)。

```powershell
python scripts/export_equity_cleaning.py "<path-to-equity-study>"
```
