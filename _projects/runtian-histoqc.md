**Status:** Research software contribution; personal public repository available.

Contributed to the development and maintenance of HistoQC during my digital pathology research at Case Western Reserve University. HistoQC automates quality-control analysis of whole-slide images and provides an interface for reviewing the resulting measurements and image regions.

### Contribution and methods

My work included scientific software development and integration of HistoQC functionality into Sedeen Viewer. I developed C++ plugins by translating Python and MATLAB image-analysis algorithms, connecting automated image quality control with an interactive slide-viewing workflow.

The personal repository contains a configurable Python quality-control pipeline, image-processing modules, and a results-review interface.
